### 单页应用工作区架构（Main Workspace）
整个产品采用高内聚的现代化 Web 单页结构（SPA），界面由五大核心功能区构成：

1. **顶部操作栏（Top Navigation Bar）**：
   - 左侧：产品 Logo 与应用标题标识。
   - 中间：全局即时搜索框（含放大镜图标、快捷键 `/` 提示、清空按钮 `×`）。
   - 右侧：视图切换按钮（网格卡片/紧凑列表）、快速新增按钮、数据中心入口（导出/导入）。
2. **左侧导航与标签过滤栏（Sidebar / Filter Rail）**：
   - 上半部系统视图：【全部灵感】、【已收藏】、【已归档】（展示各自计数徽标）。
   - 中半部标签聚合云：展示当前存在的所有标签列表，支持输入过滤标签，每个标签展示便签统计数，支持多选切换。
   - 下半部备份状态区（依据决策 dec-b17f49d8-86c3-4a74-baee-856b5d753129）：常驻展示轻量备份状态。正常状态展示微弱灰色“已备份”文本；当累积变更超20条或超7天未备份时，点亮琥珀色小圆点并显示“有未备份灵感 [立即导出]”快捷按钮。
   - 移动端/窄屏适配：折叠为轻量抽屉导航（Drawer），保障核心内容区宽度。
3. **快速捕获录入卡片（Quick Capture Card）**：
   - 常驻于主内容区顶部，呈浅色高对比度卡片样式。
   - 包含自适应伸缩文本域（Textarea）、快捷标签添加栏、`Ctrl/Cmd + Enter` 提交快捷提示与“记录灵感”按钮。
4. **灵感便签流主展区（Note Feed Grid / List）**：
   - 响应式多列瀑布流卡片展示，支持置顶区（Pinned Section）与普通流区域隔离。
   - 卡片呈现：置顶图钉图标、收藏星标、正文截断预览（支持行内代码与链接样式）、关联标签胶囊、相对时间戳。
   - 悬停浮层：展示快速操作按钮（收藏、置顶、归档、复制文本、删除）。
5. **便签详情与编辑模态弹窗（Detail & Edit Modal）**：
   - 点击便签卡片平滑弹出，支持 ESC 键关闭或点击遮罩关闭。
   - 提供阅读模式（完整 Markdown 渲染排版）与编辑模式（等宽字体实时输入区）。

### 页面适用状态具体规范
- **加载状态（Loading State）**：
  - 本地存储初始化（IndexedDB 读取）时，页面展示 6 块骨架屏（Skeleton Cards）脉冲动画，避免布局闪烁（CLS）。
- **空白状态（Empty States）**：
  - 【首次使用空状态】：居中展示清爽插画，文字提示“捕捉你的第一束灵感火花”，高亮顶部捕获框并附带“创建一条示例便签”引导按钮。
  - 【搜索/过滤无结果】：展示“未找到与 ‘xxx’ 相关的便签”，并提供一键“清空搜索与筛选”按钮，快速还原视图。
  - 【收藏/归档空状态】：分别提示“暂无收藏的灵感，点击卡片右上角星标即可加入收藏”与“归档箱空空如也”。
- **异常状态（Error States）**：
  - 【存储受限/配额满警告】：通过 StorageManager.estimate() 检测到浏览器处于受限隐私沙盒或存储配额超过阈值时，顶部展示琥珀色横幅警告：“检测到本地存储受限或配额不足，请及时导出 JSON 备份以防数据遗失”。
  - 【写入失败回退保护】：若单条便签保存因配额失败（QuotaExceededError），保留当前输入文本于输入框中不予清空，不关闭输入卡片，弹出 Toast 错误提示并提供重试与立即备份按钮，确保输入内容零丢失。
- **离线与断网状态（Offline State）**：
  - 界面左下角/设置区展示“纯本地运行，数据已离线保存在当前浏览器”，断网状态下无网络报错阻断，所有读写打标正常响应。
- **备份提醒状态（Backup Reminder State）**：
  - 未备份状态点亮时，仅在侧边栏底部展示非模态轻量提示，绝不弹出阻塞性模态框打断用户当前的灵感输入。
- **无痕/隐身浏览模式状态（Private Browsing State）**：
  - 检测到处于受限隐身环境时，顶部浮现温和提示横幅，提示用户会话关闭后本地数据可能被浏览器清除，建议随手导出备份。
