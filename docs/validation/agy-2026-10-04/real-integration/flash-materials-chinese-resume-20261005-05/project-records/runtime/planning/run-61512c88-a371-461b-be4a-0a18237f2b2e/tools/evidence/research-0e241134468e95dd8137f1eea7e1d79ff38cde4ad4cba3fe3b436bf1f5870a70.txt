    <!--lit-part Strh8kFoKX4=--><!--lit-node 0--><h2 id="instance_properties" class="heading"><!--lit-node 1--><a class="heading-anchor" href="#instance_properties">Instance properties</a></h2><!--/lit-part-->
    <p><em>Also inherits properties from its parent interface, <a href="/en-US/docs/Web/API/HTMLElement"><code>HTMLElement</code></a>.</em></p>
<p>Some properties only apply to input element types that support the corresponding attributes.</p>
<dl>
<dt id="align"><a title="The documentation about this has not yet been written; please consider contributing!" class="page-not-created" data-href="/en-US/docs/Web/API/HTMLInputElement/align"><code>align</code></a> <span role="img" class="icon icon-baseline discouraged" title="Deprecated. Not for use in new websites." aria-label="Deprecated"></span></dt>
<dd>
<p>A string that represents the alignment of the element. <em>Use CSS instead.</em></p>
</dd>
<dt id="alpha"><a href="/en-US/docs/Web/API/HTMLInputElement/alpha" title="alpha"><code>alpha</code></a> <span role="img" class="icon icon-experimental" title="Experimental. Expect behavior to change in the future." aria-label="Experimental"></span></dt>
<dd>
<p>A boolean that represents the element's <a href="/en-US/docs/Web/HTML/Reference/Elements/input/color#alpha"><code>alpha</code></a> attribute, indicating whether the color's alpha component can be manipulated by the end user and does not have to be fully opaque.</p>
</dd>
<dt id="colorspace"><a href="/en-US/docs/Web/API/HTMLInputElement/colorSpace" title="colorSpace"><code>colorSpace</code></a></dt>
<dd>
<p>A string that represents the element's <a href="/en-US/docs/Web/HTML/Reference/Elements/input/color#colorspace"><code>colorspace</code></a> attribute, indicating the <a href="/en-US/docs/Glossary/Color_space">color space</a> of the serialized CSS color (sRGB or display-p3).</p>
</dd>
<dt id="defaultvalue"><a href="/en-US/docs/Web/API/HTMLInputElement/defaultValue" title="defaultValue"><code>defaultValue</code></a></dt>
<dd>
<p>A string that represents the default value as originally specified in the HTML that created this object.</p>
</dd>
<dt id="dirname"><a href="/en-US/docs/Web/API/HTMLInputElement/dirName" title="dirName"><code>dirName</code></a></dt>
<dd>
<p>A string that represents the directionality of the element.</p>
</dd>
<dt id="incremental"><a title="The documentation about this has not yet been written; please consider contributing!" class="page-not-created" data-href="/en-US/docs/Web/API/HTMLInputElement/incremental"><code>incremental</code></a> <span role="img" class="icon icon-nonstandard" title="Non-standard. Check cross-browser support before using." aria-label="Non-standard"></span></dt>
<dd>
<p>A boolean that represents the search event fire mode, if <code>true</code>, fires on every keypress, or on clicking the cancel button; otherwise fires when pressing <kbd>Enter</kbd>.</p>
</dd>
<dt id="labels"><a href="/en-US/docs/Web/API/HTMLInputElement/labels" title="labels"><code>labels</code></a> <span class="badge inline readonly" title="This value may not be changed.">Read only</span></dt>
<dd>
<p>Returns a list of <a href="/en-US/docs/Web/HTML/Reference/Elements/label"><code>&lt;label&gt;</code></a> elements that are labels for this element.</p>
</dd>
<dt id="list"><a href="/en-US/docs/Web/API/HTMLInputElement/list" title="list"><code>list</code></a> <span class="badge inline readonly" title="This value may not be changed.">Read only</span></dt>
<dd>
<p>Returns the element pointed to by the <a href="/en-US/docs/Web/HTML/Reference/Elements/input#list"><code>list</code></a> attribute. The property may be <code>null</code> if no HTML element is found in the same tree.</p>
</dd>
<dt id="multiple"><a href="/en-US/docs/Web/API/HTMLInputElement/multiple" title="multiple"><code>multiple</code></a></dt>
<dd>
<p>A boolean that represents the element's <a href="/en-US/docs/Web/HTML/Reference/Elements/input#multiple"><code>multiple</code></a> attribute, indicating whether more than one value is possible (e.g., multiple files).</p>
</dd>
<dt id="name"><a href="/en-US/docs/Web/API/HTMLInputElement/name" title="name"><code>name</code></a></dt>
<dd>
<p>A string that represents the element's <a href="/en-US/docs/Web/HTML/Reference/Elements/input#name"><code>name</code></a> attribute, containing a name that identifies the element when submitting the form.</p>
</dd>
<dt id="popovertargetaction"><a href="/en-US/docs/Web/API/HTMLInputElement/popoverTargetAction" title="popoverTargetAction"><code>popoverTargetAction</code></a></dt>
<dd>
<p>Gets and sets the action to be performed (<code>"hide"</code>, <code>"show"</code>, or <code>"toggle"</code>) on a popover element being controlled by an <a href="/en-US/docs/Web/HTML/Reference/Elements/input"><code>&lt;input&gt;</code></a> element of <code>type="button"</code>. It reflects the value of the <a href="/en-US/docs/Web/HTML/Reference/Elements/input#popovertargetaction"><code>popovertargetaction</code></a> HTML attribute.</p>
</dd>
<dt id="popovertargetelement"><a href="/en-US/docs/Web/API/HTMLInputElement/popoverTargetElement" title="popoverTargetElement"><code>popoverTargetElement</code></a></dt>
<dd>
<p>Gets and sets the popover element to control via an <a href="/en-US/docs/Web/HTML/Reference/Elements/input"><code>&lt;input&gt;</code></a> element of <code>type="button"</code>. The JavaScript equivalent of the <a href="/en-US/docs/Web/HTML/Reference/Elements/input#popovertarget"><code>popovertarget</code></a> HTML attribute.</p>
</dd>
<dt id="step"><a href="/en-US/docs/Web/API/HTMLInputElement/step" title="step"><code>step</code></a></dt>
<dd>
<p>A string that represents the element's <a href="/en-US/docs/Web/HTML/Reference/Elements/input#step"><code>step</code></a> attribute, which works with <a href="/en-US/docs/Web/HTML/Reference/Elements/input#min"><code>min</code></a> and <a href="/en-US/docs/Web/HTML/Reference/Elements/input#max"><code>max</code></a> to limit the increments at which a numeric or date-time value can be set. It can be the string <code>any</code> or a positive floating point number. If this is not set to <code>any</code>, the control accepts only values at multiples of the step value greater than the minimum.</p>
</dd>
<dt id="type"><a href="/en-US/docs/Web/API/HTMLInputElement/type" title="type"><code>type</code></a></dt>
<dd>
<p>A string that represents the element's <a href="/en-US/docs/Web/HTML/Reference/Elements/input#type"><code>type</code></a> attribute, indicating the type of control to display. For possible values, see the documentation for the <a href="/en-US/docs/Web/HTML/Reference/Elements/input#type"><code>type</code></a> attribute.</p>
</dd>
<dt id="usemap"><a title="The documentation about this has not yet been written; please consider contributing!" class="page-not-created" data-href="/en-US/docs/Web/API/HTMLInputElement/useMap"><code>useMap</code></a> <span role="img" class="icon icon-baseline discouraged" title="Deprecated. Not for use in new websites." aria-label="Deprecated"></span></dt>
<dd>
<p>A string that represents a client-side image map.</p>
</dd>
<dt id="value"><a href="/en-US/docs/Web/API/HTMLInputElement/value" title="value"><code>value</code></a></dt>
