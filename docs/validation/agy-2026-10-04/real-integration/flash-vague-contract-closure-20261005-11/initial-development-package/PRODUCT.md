## 秒级随手灵感极速捕获功能

ID：feature-quick-capture；关联需求：block-scope-core-boundaries；依赖：page-main-workspace

### 功能定义与交互规范
1. **自动聚焦与极速唤起**：
   - 用户打开应用时，光标默认聚焦于输入框；若页面处于非输入焦点状态，按下快捷键 `N` 立即滚动至顶部并聚焦输入框。
2. **自适应高度与多行排版**：
   - 默认高度为单行输入框（占位提示：“随手记下新灵感... 按 Ctrl+Enter 保存，输入 #添加标签”）。
   - 随输入行数增加，输入框平滑向上/向下展开至最多 8 行高度，超出后出现内部平滑滚动条。
3. **快捷键提交与提交防抖**：
   - 支持键盘 `Ctrl + Enter` (Windows/Linux) 或 `Cmd + Enter` (macOS) 触发瞬时提交。
   - 点击右下角“记录”按钮亦可提交。提交后输入框清空并恢复单行初始状态。
4. **智能行内标签提取**：
   - 支持在正文任意位置输入 `#标签名`（如 `#React 探究并发渲染特性`）。
   - 提交时自动通过正则匹配提取标签名并归并至便签标签属性中，正文可保留完整语义。
   - 输入框下方同时提供最近使用的快捷标签胶囊，点击即可一键附加到当前便签。
5. **边界条件与失败回退保护**：
   - 禁止提交仅含空格或换行符的无效内容。内容为空时“记录”按钮置灰禁用；强制按快捷键时输入框执行左右轻微抖动动画，内容完整保留。
   - 若本地 IndexedDB 写入异常（如存储空间不足 QuotaExceededError），输入卡片坚决不关闭，输入框内的文本与标签完整保留，界面弹出明确错误提示：“保存失败：本地存储已满，请导出备份或清理空间”，用户可在复制文本或清理空间后重新点击保存。

### 验收标准（Given / When / Then）
- **场景 1：快捷键常规提交**
  - **Given** 用户在工作区页面，
  - **When** 用户在捕获输入框键入“验证 Vite 静态构建输出 #前端”，并按下 `Ctrl + Enter`，
  - **Then** 输入框瞬间清空并收缩为单行，便签流顶部以淡入下移动画立即插入该卡片，包含正文与 `#前端` 标签，对应本地数据即刻持久化。
- **场景 2：空文本校验拦截**
  - **Given** 捕获输入框无内容或仅有换行空格，
  - **When** 用户尝试点击“记录”或按下 `Cmd + Enter`，
  - **Then** 提交动作被拦截，输入框外边框出现红色警示抖动，列表不增加任何卡片，焦点保留在输入框。
- **场景 3：存储写入失败保护**
  - **Given** 浏览器处于极端配额满状态，
  - **When** 用户键入灵感并尝试提交，
  - **Then** 捕获失败，输入框内容完整保留不被清空，卡片不关闭，弹出错误 Toast，提供重试与导出入口。

## 便签流多视图展示与卡片状态管理功能

ID：feature-note-card-view；关联需求：block-scope-core-boundaries；依赖：page-main-workspace

### 功能定义与交互规范
1. **双布局形态自适应**：
   - **瀑布流卡片视图（Card Grid）**：针对零散碎片想法，多列自适应卡片展示，卡片高度由内容决定，视觉层次生动。
   - **紧凑列表视图（Compact List）**：针对高密度检索场景，单行展示关键文本、主要标签与时间，便于快速扫读。
   - 用户切换布局形态后，偏好自动保存至本地，刷新保持一致。
2. **多维状态管理与视觉标识**：
   - **置顶（Pinned）**：卡片固定在列表首部独立“置顶灵感”分类区域，右上角显示高亮图钉标识。
   - **收藏（Favorited）**：卡片提供星标按钮，点击即可加入“已收藏”快捷视图。
   - **归档（Archived）**：对于已消化或阶段性完结的灵感，点击“归档”移出常规视图，减少干扰，可在“归档箱”中找回。
   - **软删除与防误触撤销（Soft Delete & Undo）**：点击删除后，便签从当前列表移除并进入临时回收池，界面底部弹出持续 5 秒的“已删除 [撤销]”浮动通知。
3. **卡片信息层级展示**：
   - 顶部：置顶指示、收藏星标、相对时间戳（如“刚刚”、“10分钟前”、“前天”）。
   - 中间：正文摘要（最多展示 5 行，超出部分渐变半透明截断并提示“展开全部”），保留粗体、行内代码与超链接渲染。
   - 底部：标签胶囊组（可点击直接按该标签筛选）、快速操作工具条（复制文本、归档、删除）。
4. **失败处理与状态保留**：
   - 若置顶、收藏或归档状态本地写入失败，卡片状态立刻回滚至点击前状态，并弹出提示“操作未能保存至本地”，不丢失原有便签内容。
   - 若软删除持久化失败，便签从回收池回退到原列表位置，确保卡片内容不意外丢失。

### 验收标准（Given / When / Then）
- **场景 1：置顶与排序即时生效**
  - **Given** 列表中存在多条便签，
  - **When** 用户点击某中间位置便签的图钉按钮，
  - **Then** 该便签立刻平滑升至“置顶区域”首位，图钉图标由轮廓线变为实心高亮状态。
- **场景 2：删除与撤销保护**
  - **Given** 用户在卡片上点击“删除”图标，
  - **When** 卡片执行淡出消失，
  - **Then** 页面底部立即弹出带“撤销”按钮的 Toast；若用户在 5 秒内点击“撤销”，该便签毫秒级在原位置恢复显示。
- **场景 3：删除超时持久化失败回退**
  - **Given** 用户删除了某便签且 5 秒倒计时结束，
  - **When** 本地数据库写入删除失败，
  - **Then** 界面弹出“删除失败，已恢复显示”，该卡片重新呈现在列表中，数据完整保留。

## 多维灵活标签与分类过滤功能

ID：feature-tag-organization；关联需求：block-scope-core-boundaries；依赖：page-main-workspace

### 功能定义与交互规范
1. **便签多标签支持与格式规范**：
   - 单条便签支持关联 0 到多个标签，标签名支持中英文、数字及连字符（如 `#架构设计`、`#bug-fix`、`#2026计划`）。
   - 自动过滤标签中非法符号，标签长度限制为 1 到 20 字符。
2. **全局标签池聚合与统计**：
   - 侧边栏“标签”面板自动遍历全部非删除便签，汇总所有独立标签并按关联便签数降序排列（如 `#灵感 (15)`、`#前端 (8)`）。
   - 提供标签过滤搜索框，当标签数量较多时支持即时键入过滤标签名。
3. **单选与多选交集组合过滤**：
   - 单击标签：激活该标签过滤，便签流仅展示包含该标签的条目，顶部展示筛选条件胶囊 `标签: #xxx [×]`。
   - `Ctrl/Cmd` + 单击多个标签：开启多标签“交集（AND）”过滤模式，例如同时勾选 `#React` 与 `#优化`，仅展示同时包含这两个标签的高价值便签。
4. **标签全局重命名与批量更新失败保护**：
   - 鼠标悬停侧边栏标签提供“编辑”菜单，支持对标签进行全局重命名，系统在本地数据库事务中批量更新所有包含该标签的便签。
   - 若重命名批量写入过程中途发生存储异常，事务自动回滚，保持原有标签名称不变，弹窗提示“重命名未完成，已恢复原名称”，关联便签内容不损坏。
   - 当某标签关联的便签全部删除或移除该标签后，空标签自动从列表收起，保持标签池精炼。

### 验收标准（Given / When / Then）
- **场景 1：标签单选过滤**
  - **Given** 侧边栏存在 `#工具推荐 (5)` 标签，
  - **When** 用户点击该标签，
  - **Then** 便签流立即刷新，仅显示打有 `#工具推荐` 的 5 条卡片，顶部出现该标签过滤胶囊。
- **场景 2：标签批量重命名**
  - **Given** 系统中有 3 条便签包含 `#old-name` 标签，
  - **When** 用户在侧边栏对该标签重命名为 `#new-name` 并确认，
  - **Then** 3 条便签底部的标签胶囊全部同步变为 `#new-name`，侧边栏标签统计与筛选无缝更新。
- **场景 3：标签批量重命名异常回滚**
  - **Given** 用户对标签发起重命名操作，
  - **When** 本地事务写入遭遇配额中断，
  - **Then** 事务自动回滚，原有便签的标签保持 `#old-name`，弹窗提示失败并建议导出备份。

## 即时全文模糊检索与关键词高亮功能

ID：feature-search-filter；关联需求：block-scope-core-boundaries；依赖：page-main-workspace

### 功能定义与交互规范
1. **即时无延迟响应与输入防抖（待验证目标）**：
   - 顶部搜索框键入时设置 80ms 轻度防抖，在纯前端内存索引中执行模糊匹配；在 1,000 条便签基准下检索端到端响应时间目标小于 150ms。
   - 匹配范围包括：便签正文文本、所含标签名称、创建时间等元信息。
2. **关键词动态高亮渲染**：
   - 搜索匹配到的便签卡片中，所有命中的关键词文本自动被微黄色背景的 `<mark class="highlight">` 标签包裹高亮呈现，便于一眼定位关键依据。
3. **快捷键唤醒与快捷重置**：
   - 在主界面任意非输入状态下，敲击键盘斜杠键 `/`，光标立即聚焦至搜索框并全选已有内容。
   - 搜索框右侧常驻清空按钮 `×`，点击或直接按下键盘 `Escape` 键，立即清空搜索输入并恢复未过滤列表，光标自动失焦。
4. **组合检索与异常状态兼容**：
   - 搜索与侧边栏的视图状态（全部/收藏/归档）及标签过滤条件完全兼容，采用逻辑“与（AND）”叠加过滤。
   - 若输入超长特殊正则字符（如 `\/*?[]` 等），系统进行安全转义，不引起渲染崩溃，无匹配时展示清晰空状态。

### 验收标准（Given / When / Then）
- **场景 1：关键词即时搜索与高亮**
  - **Given** 列表中存在包含“IndexedDB 持久化方案”的便签，
  - **When** 用户在搜索框键入 `indexeddb`（不区分大小写），
  - **Then** 列表仅保留匹配卡片，卡片正文中对应的 `IndexedDB` 词段呈现高亮背景。
- **场景 2：快捷键清除与视图还原**
  - **Given** 当前处于搜索结果筛选状态，
  - **When** 用户按下键盘 `Escape` 键，
  - **Then** 搜索框文本被清空，光标失焦，便签列表以平滑动画恢复完整全量显示。
- **场景 3：特殊字符搜索防崩**
  - **Given** 用户在搜索框键入连续正则特殊字符 `([*+?^$`，
  - **When** 触发过滤，
  - **Then** 系统安全转义该文本并展示“未找到匹配便签”，页面不报错崩溃。

## 便签详情模态展示与 Markdown 实时编辑功能

ID：feature-note-detail-edit；关联需求：block-scope-core-boundaries；依赖：page-main-workspace

### 功能定义与交互规范
1. **沉浸式模态详情窗口**：
   - 点击任意卡片正文区域，界面居中弹出阅读/编辑弹窗，背景呈现半透明遮罩与轻量高斯模糊，支持键盘 `Esc` 快捷关闭。
2. **轻量 Markdown 排版解析**：
   - 支持常用 Markdown 语法解析：
     - 标题层级（`#` 至 `###`）
     - 无序列表与有序列表（`-`, `1.`）
     - 任务清单（`- [ ]` 与 `- [x]`），复选框在阅读状态下支持直接点击切换完成状态，并同步持久化
     - 行内代码与多语言代码块（带基础语法着色与等宽字体）
     - 外部超链接自动解析，强制添加 `target="_blank"` 与 `rel="noopener noreferrer"` 属性保障安全。
3. **一键复制代码与快捷外跳**：
   - 代码块右上角浮动“复制”按钮，点击后调用浏览器剪贴板并在按钮上显示“已复制 √”（2秒后复原）。
   - 识别到的 URL 链接旁边显示小外链图标，点击直接在新标签页打开，不阻断当前应用上下文。
4. **无缝内联编辑与异常保存保护**：
   - 弹窗顶部提供“编辑 / 预览”切换开关，亦可双击正文直接切入编辑模式。
   - 编辑模式提供带行号与等宽字体的多行编辑器，支持全量文本修改及标签增删。
   - 支持 `Ctrl/Cmd + S` 快捷保存；若直接关闭弹窗且内容发生变动，自动触发本地异步保存。
   - **保存失败保护**：若本地存储写入异常（配额超限或数据库锁冲突），弹窗保持开启状态不予关闭，编辑器中的修改内容完整保留在文本域中，弹窗顶部显示红色错误警告：“本地保存失败，请检查存储容量或导出备份”，并提供“重试保存”按钮，防止编辑内容丢失。

### 验收标准（Given / When / Then）
- **场景 1：Markdown 任务清单即时勾选**
  - **Given** 某便签包含 `- [ ] 购买云服务器` 任务项，
  - **When** 用户在详情弹窗中直接点击该复选框，
  - **Then** 复选框变为勾选状态，文字呈现删除线划去样式，对应本地持久化数据同步更新。
- **场景 2：代码块一键复制**
  - **Given** 便签中包含 JavaScript 代码段，
  - **When** 用户点击代码块右上角的“复制”图标，
  - **Then** 剪贴板中成功写入该代码纯文本，按钮图标变为绿色对勾提示“已复制”。
- **场景 3：编辑保存失败回退**
  - **Given** 用户在编辑弹窗中修改了长文本，
  - **When** 用户点击完成保存但本地存储抛出配额异常，
  - **Then** 弹窗不关闭，编辑文本完整保留，界面提示保存失败并保留重试按钮。

## 本地数据备份导出、恢复与温和防丢提醒功能

ID：feature-data-portability；关联需求：block-scope-core-boundaries；依赖：page-main-workspace

### 功能定义与交互规范
1. **一键全量导出为结构化 JSON 备份**：
   - 支持将当前本地保存的所有便签数据（包含 ID、正文、创建与修改时间、标签、置顶/收藏状态、版本元数据）一键打包并导出为符合标准规范的 JSON 文件。
   - 导出的文件名遵循规则：`spark-notes-backup-YYYY-MM-DD.json`，方便用户归档存放。
2. **Markdown 格式导出支持**：
   - 支持将所有便签批量导出为一个整理好的 Markdown 汇总文件或多文件压缩包，便签标签转换为 Markdown FrontMatter，以便无缝导入 Obsidian、Notion 或本地开发文档中。
3. **安全数据导入与冲突消解**：
   - 提供拖拽上传或文件选择器导入外部 JSON 备份文件。
   - **格式强校验**：导入前对文件进行严格 JSON Schema 与结构校验；若文件损坏或格式不匹配，明确弹窗拦截报错，不触碰本地任何既有数据。
   - **冲突合并策略**：
     - **智能增量合并（推荐）**：根据便签 ID 与更新时间戳比对，新记录直接补入，已存在记录保留更新时间较新的一方，不覆盖更新的数据。
     - **全量覆盖恢复**：清空当前现有便签，完全以备份文件为准进行恢复（执行前强制弹窗二次确认）。
4. **温和防丢备份提醒（依据决策 dec-b17f49d8-86c3-4a74-baee-856b5d753129）**：
   - **元数据追踪**：本地存储元数据中记录上次导出时间戳（`lastBackupAt`）与未备份变更计数（`unbackedChangesCount`）。
   - **阈值触发**：当未备份便签变更（新增/编辑/归档/删除）累计达到 20 条，或距离上次备份时间超过 7 天时，在侧边栏底部温和点亮琥珀色提示圆点，并展示微文案“有未备份灵感 [立即导出]”。
   - **对抗系统清理与驱逐**：该机制与 MDN 阐明的浏览器 LRU 静默驱逐及 Safari 7 天无交互清理机制紧密契合，确保用户在系统清除数据前得到温和提示。
   - **非侵入式**：不使用打断式弹窗，不阻断正常记录流程；用户点击立即导出后直接触发浏览器下载，导出成功后计数器清零，提示点恢复微弱灰色。
5. **失败处理与操作保护**：
   - 导出生成 Blob 或触发下载失败时，保持备份面板打开，提示“导出失败，请重试”，本地数据完整保留。
   - 导入解析或写入数据库中断时，事务自动回滚，本地既有数据完整保持导入前状态不变，界面清晰告知失败原因（如“第 12 条记录格式错误”）。
   - 提供“清空所有本地数据”的高级选项，点击后强制弹出红色警示对话框，要求用户在输入框键入 `CLEAR` 确认方可执行，防止误触。

### 验收标准（Given / When / Then）
- **场景 1：JSON 备份导出与计数复位**
  - **Given** 用户本地有 20 条灵感便签，且状态栏显示琥珀色未备份提醒，
  - **When** 用户点击“立即导出”，
  - **Then** 浏览器触发 `spark-notes-backup-YYYY-MM-DD.json` 文件下载，状态栏提醒点熄灭，未备份变更计数归零。
- **场景 2：非法格式导入拦截与数据安全**
  - **Given** 用户上传了一份损坏的非 JSON 文本文件，
  - **When** 系统执行文件读取校验，
  - **Then** 弹窗提示“导入失败：文件格式不合法”，本地现有便签数据完整无损，无任何记录被篡改或覆盖。
- **场景 3：增量智能合并恢复**
  - **Given** 用户本地存有 10 条便签，备份文件中包含 15 条（含 5 条新便签与 2 条更新版本），
  - **When** 用户选择“智能增量合并”导入，
  - **Then** 导入完成提示“成功新增 5 条，更新 2 条”，主页面工作区无刷新即刻展示合并后的 15 条完整便签。
