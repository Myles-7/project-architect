 InputEvent: isComposing property

 Baseline 2026 

 Newly available

 Since September 2026, this feature works across the latest devices and browser versions. This feature might not work in older devices or browsers.

 See full compatibility

 Learn more

 The InputEvent.isComposing read-only property returns a
boolean value indicating if the event is fired after
 compositionstart and before compositionend .

 In this article

 Value 

 Examples 

 Specifications 

 Browser compatibility 

 See also 

 Value 

 A boolean.

 Examples 

 js 
 const inputEvent = new InputEvent("syntheticInput", false);
console.log(inputEvent.isComposing); // return false
