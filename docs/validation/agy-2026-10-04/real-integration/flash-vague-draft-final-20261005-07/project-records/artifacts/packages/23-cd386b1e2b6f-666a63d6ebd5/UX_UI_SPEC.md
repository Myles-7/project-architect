## 单页应用主工作区页面设计与状态规范

ID：page-main-workspace；关联需求：block-scope-core-boundaries；依赖：block-scope-core-boundaries

### 单页应用工作区架构（Main Workspace - 包含回收区生命周期）
整个产品采用高内聚的现代化 Web 单页结构（SPA），界面由五大核心功能区构成：

1. **顶部操作栏（Top Navigation Bar）**：
   - 左侧：产品 Logo 与应用标题标识。
   - 中间：全局即时搜索框（含放大镜图标、快捷键 `/` 提示、清空按钮 `×`）。
   - 右侧：视图切换按钮（网格卡片/紧凑列表）、快速新增按钮、数据中心入口（导出/导入）。
2. **左侧导航与标签过滤栏（Sidebar / Filter Rail）**：
   - 上半部系统视图：【全部灵感】、【已收藏】、【已归档】、【回收区】（展示各自计数徽标）。当回收区存在超过 7 天保留期限的便签时，【回收区】入口旁常驻琥珀色过期预警圆点。
   - 中半部标签聚合云：展示当前存在的所有标签列表，统计数仅统计活跃及归档便签，排除回收区便签。
   - 下半部备份状态区（依据决策 dec-b17f49d8-86c3-4a74-baee-856b5d753129）：常驻展示轻量备份状态。累积变更超20条或超7天未备份时点亮琥珀色提示点与“立即导出”快捷按钮。
   - 移动端/窄屏适配：折叠为轻量抽屉导航（Drawer）。
3. **快速捕获录入卡片（Quick Capture Card）**：
   - 常驻于主内容区顶部，提交后生成活跃状态便签。
4. **灵感便签流主展区（Note Feed Grid / List）**：
   - 响应式多列瀑布流卡片展示，支持置顶区（Pinned Section）与普通流区域隔离。
   - 悬停浮层：展示快速操作按钮（收藏、置顶、归档、复制文本、移入回收区）。
   - 回收区视图（Recycle Bin View）：卡片流独立展示处于回收区的便签，每张卡片顶部展示“已在回收区 X 天 / 还剩 Y 天”状态胶囊，操作按钮替换为【还原】与【彻底删除】。
5. **便签详情与编辑模态弹窗（Detail & Edit Modal）**：
   - 点击卡片展开居中模态弹窗。若为回收区便签，强制展示只读保护条，禁用直接编辑，提供【还原】与【彻底删除】按钮。

### 页面适用状态具体规范
- **加载状态（Loading State）**：本地存储初始化时展示 6 块骨架屏（Skeleton Cards）脉冲动画。
- **空白状态（Empty States）**：
  - 【首次使用空状态】：居中展示“捕捉你的第一束灵感火花”。
  - 【搜索/过滤无结果】：展示“未找到相关便签”，提供一键重置按钮。
  - 【收藏/归档空状态】：提示“暂无收藏灵感”或“归档箱空空如也”。
  - 【回收区空状态】：提示“回收区空空如也，被删除的灵感将在此保留 7 天并支持随时还原”。
- **回收区视图与过期提示状态（Recycle Bin & Expiration State）**：
  - 依据已确认决策 dec-cd105627-1e53-4251-9f8e-9422bdfbbd5c，当回收区存在超过 7 天保留期限的便签时，顶部常驻琥珀色提示横幅“有 X 条便签已超过 7 天保留期限”，提供【清空已过期便签】与【一键彻底清空】操作按钮；点击后弹出二次确认对话框，用户确认后执行物理彻底删除。
- **异常状态（Error States）**：
  - 【存储受限/配额满警告】：配额超限横幅告警。
  - 【写入与删除失败保护】：便签移入回收区或还原失败时，界面弹出 Toast 提示并保留原位置状态，绝不损坏或静默丢弃内容。
- **离线与断网状态（Offline State）**：纯本地离线运行。
- **备份提醒状态（Backup Reminder State）**：非模态轻量提示。
- **无痕/隐身浏览模式状态（Private Browsing State）**：顶部浮现温和提示横幅建议导出。
