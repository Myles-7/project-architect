## 功能特性：输入 300ms 防抖实时反馈、安全展示与失败保留输入

ID：blk-feat-input-display；关联需求：blk-prod-scope、blk-prod-outcomes；依赖：blk-prod-scope

支持在桌面端输入框中录入项目名文本，采用实时防抖反馈机制替代传统确认按钮。
- 正常输入状态：用户在输入框中键入有效非空字符，系统监听 input 事件并在输入变动后等待 300ms；若 300ms 内无新输入，自动触发非空校验并通过 Node.textContent 安全渲染至顶部大字展示区，自动清除先前旧错误提示，输入框保持现有输入文本便于随时微调。
- 中文输入法合成防误触：基于 InputEvent.isComposing 与 compositionstart/compositionend 事件，在用户拼音输入未确认上屏期间挂起防抖计时，待选词确认（compositionend）后立即启动 300ms 倒计时，避免未完成拼音草稿提前上屏。
- 连续键入状态：若用户在 300ms 倒计时未结束前继续键入新字符，立即重置并重新开启 300ms 计时器，避免中途无效频繁重绘。
- 清空取消状态：若在 300ms 防抖等待期间用户点击清空按钮，立即取消处于待执行状态的防抖展示任务，并清空展示区与输入框，杜绝旧文本幽灵回显。
- 空值状态：输入内容为空字符串或全为空白字符（空格、制表符）时，300ms 防抖结束后阻断展示区大字更新（展示区恢复为初始占位符），在输入框下方就地显示红色警示‘项目名不能为空，请输入有效字符’，且严格保留用户已输入的空格等字符，输入框保持焦点。
- 异常保护状态：若执行过程发生未知运行时错误，立即捕获异常并显示轻量告警条，输入框现有文本严格保留，不重置页面，允许用户修复或继续编辑。
- 初始/离线状态：首次打开展示区显示灰色占位文字‘【等待输入核对】’，完全支持纯离线本地加载运行。

## 功能特性：一键清空、取消待展示任务与状态复位

ID：blk-feat-reset；关联需求：blk-prod-scope、blk-prod-outcomes；依赖：blk-prod-scope

提供一键清空与重置功能，帮助用户在完成一轮项目名核对后快速复位界面，并与 300ms 防抖调度器形成严密联动：
- 立即取消机制：用户点击清空按钮时，系统第一优先级调用 DebounceScheduler.cancel()，立即销毁所有正在排队等待执行的 300ms 待展示任务，并重置输入法合成状态标记，从根本上杜绝已清空内容被延迟回调“幽灵覆写”的风险。
- 正常即时复位：依据用户已确认决策（即时直接清空），用户点击清空按钮后系统立即执行复位，不弹出阻断式确认弹窗。顶部展示区复位为初始灰色占位提示（‘【等待输入核对】’），输入框内容清空（value = ''），任何正在显示的校验报错信息被移除，光标自动重新聚焦在输入框内（.focus()），方便立即开始新一轮输入。
- 容错与恢复：清空操作不依赖外部环境，纯客户端内存重置；若清空过程抛出异常，捕获错误并保留现有视图，控制台输出日志并提示用户手动刷新，不发生页面白屏。
- 幂等性：在空页面状态下重复点击清空不会产生任何副作用或错误。
