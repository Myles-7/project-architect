## Implemented behavior

- One provider invocation per registered request. No hidden stream-to-command fallback, context truncation, provider retry or natural-language JSON recovery. Planning accepts only explicit terminal result events and rejects historical single JSON envelopes; non-planning compatibility readers may still read them. Planning has no implicit duration gate; explicit legacy timeout remains supported.
- Append-only stdout/stderr/invocation/exit records go to request.logPath. Only one bounded current event and a bounded stderr tail are held in memory. Cancellation kills the local child process tree.
- Preflight verifies the requested model against the actual catalog and verifies the selected init model. The custom executor exposes finish, local MCP tools, and view_file only for exact registered original images. Native shell, writes, delegation and unknown MCP calls are denied. Headless MCP internal permissions require the scoped skip-permissions flag even after a hook allows the call; the custom subset and hard gate remain in force.
- The material service accepts registered ids, canonical permitted roots, byte hashes, range reads, image bytes and exact paths. PDF/DOCX require their existing extracted-text artifacts; binary data is not pretended to be text.
- Official research fetches HTTPS only on configured officialHosts and validates redirects, preserving source/date/hash/content. Defaults are intentionally bounded. Arbitrary target technologies require the root integration to register their official hosts through advanced settings; this service exposes that configuration already.
- Experiments mount exactly one independently created source directory, read-only, with network none, no host secrets/home/project/socket mount, no extra capabilities, bounded process/memory resources and generated commands. Source, environment and logs are preserved. Online preparation only pulls fixed images/builds fixed pinned dependency-manager instructions, never submitted source. npm lifecycle scripts and pip source builds are disabled. Chromium preparation adds the pinned Playwright package. No unexecuted run is pass.
